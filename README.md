# TableTop Kingdom 🎲

Aplicación FrontEnd simulada para la venta de juegos de mesa.

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Roles
- **Administrador**: gestiona usuarios registrados
- **Cliente**: navega categorías y juegos

## Páginas principales
- index.html → Página principal
- login.html → Inicio de sesión
- recuperar.html → Recuperar contraseña
- perfil.html → Modificar perfil
- pages/registro.html → Registro de usuarios
- pages/admin.html → Panel administrador
- pages/estrategia.html → Categoría Estrategia
- pages/familia.html → Categoría Familia
- pages/cartas.html → Categoría Cartas
- pages/misterio.html → Categoría Misterio
